# CRUMBOPOLIS / パンくず都市計画局

**一片の食べ残しから、国家は始まる。** 食卓のパンくずを都市区画に見立て、アリの物流・食料枯渇・税収・道路建設を追跡する完全クライアント型シミュレーション。

## 遊び方
- 地図をクリックして食パンまたは砂糖の区画を建設する
- ドラッグしてアリの専用道路を敷設し、配送効率を変える
- 撤去モードで区画や道路を再開発する
- 気象変動、速度変更、熱量可視化、一時停止、初期化を試す

## なぜ面白いのか
ゼロから小さな交通網が立ち上がり、アリが規則に従って動くため、都市運営らしいフィードバックがある。短時間で「道路を引いたら本当に早くなる？」という実験ができる。

## どこが無駄なのか
食卓で余ったパンくずに都市計画と財政統計を導入しても、社会的な問題は何一つ解決しない。

## 使用技術
HTML/CSS/Canvas 2D、requestAnimationFrame、ステートマシン型エージェント、幾何学的線分距離計算、localStorage、ResizeObserver。ビルド不要・API不要。外部フォントが取得できなくても動作する。

## 記録
自治体の地形、道路、税収、財政履歴を localStorage に保存。セーブデータには機密情報を含まない。
